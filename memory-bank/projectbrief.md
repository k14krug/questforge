# Project Brief

QuestForge is a web application designed to create and play AI-generated cooperative role-playing games (RPGs). The platform utilizes a Python-based backend (e.g., Flask) with Socket.IO for real-time communication. It leverages a tiered system of AI language models to generate narrative content, campaign structures, and in-game responses. A key feature is the dynamic action resolution system, where character skills and simulated dice rolls determine the outcome of player actions. Campaigns are built from “templates,” and gameplay occurs in a rich, browser-based interface managed by a customizable AI Game Master (GM). The core focus is on providing a deep, mechanically engaging, and narratively consistent experience.
